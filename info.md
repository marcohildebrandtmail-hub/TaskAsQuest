# Task as Quest

Diese Integration verbindet deinen Home Assistant mit dem **Task as Quest** Gamification System.

Mit der Integration kannst du über die Home Assistant UI Regeln anlegen, die automatisch Quests in der PocketBase-Datenbank erstellen, wenn bestimmte Sensor-Werte über- oder unterschritten werden, oder wenn Geräte ausfallen.
Zusätzlich werden End-to-End verschlüsselte Quests (Allianz-Quests) vollständig unterstützt.

Bitte lese dir die [README](https://github.com/marcohildebrandtmail-hub/TaskAsQuest/blob/main/README.md) durch, um die Konfiguration und Einrichtung korrekt durchzuführen (vor allem im Bezug auf den Recovery Code).
